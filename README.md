# PFS-DSA-DAY2-3


-# Day 2&3 – Array Data Structure Operations (16-06-2026 && 17-06-2026)

This repository contains my Day 2 practice programs from the Python Full Stack (PFS) Data Structures and Algorithms course. Today's session focused on understanding and implementing the basic operations performed on arrays using Python. Instead of relying solely on built-in functions, the programs demonstrate the logic behind each operation to strengthen problem-solving skills and build a strong foundation in Data Structures.

### Topics Covered

* Array Introduction
* Insert at Beginning
* Insert at End
* Delete from Beginning
* Delete from End
* Insert by Position
* Delete by Position
* Delete by Value
* Search an Element
* Update an Element
* Reverse an Array
* Rotate Array Left
* Rotate Array Right

The implementations emphasize array indexing, element shifting, traversal, searching, updating, reversing, and rotation techniques. These exercises helped me understand how array operations work internally and improved my coding and algorithmic thinking as part of my daily PFS DSA learning journey.
